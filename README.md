# Telegram → Facebook 群消息转发

在 **Telegram 网页标签页** 里完成全部设置：顶部配置 FB 群，在每位发言者消息下勾选「转发到 FB」。

## 使用

1. 点击扩展图标 → **打开 Telegram 监听标签页**
2. 进入目标群聊
3. 页面 **顶部蓝条**：填写 Facebook 群链接（每行一个）→ 勾选「启用转发」→ **保存 FB 群设置**
4. 在群里 **每条他人消息下方** 勾选「转发此人消息到 FB」，或点「转发」立即群发
5. 之后该人每条新消息会自动发到所有已配置的 FB 群（可勾选多人）

## 说明

- **Facebook 登录**：只要在 Chrome 中登录过 Facebook 即可（任意标签页登录一次），**无需打开任何群聊页**，也无需保持 FB 页面打开
- **静默发送**：转发通过扩展后台 API 完成，不会刷新页面、不会抢占焦点、不会模拟鼠标点击
- **群发**：配置多个 `messages/t/数字` 链接后，一条消息会自动分发到所有群
- 废话过滤：顶部蓝条「废话过滤」展开后填写，每行一条
- 请保持 **Telegram 监听标签页** 打开并已登录

## 安全与合规

- **数据存储**：配置与转发日志保存在本机 `chrome.storage`；排队转发**不会**把图片 base64 写入磁盘，仅在发送瞬间于内存中处理
- **消息来源校验**：仅接受来自 `web.telegram.org` 的转发请求，防止其他页面冒充
- **Facebook 自动化风险**：本扩展使用非官方 Messenger API 自动发消息，可能触发 Facebook **限流、安全验证（checkpoint）或账号限制**；请控制群发频率，并自行评估合规风险
- **隐私**：无开发者服务器；请勿在不可信环境安装修改版扩展

## 故障排查（popup 日志分类）

| 分类 | 含义 | 建议 |
|------|------|------|
| 登录/会话 | Cookie 或 dtsg 失效 | 在 Chrome 重新打开 facebook.com 登录 |
| 网络 | 连接超时或失败 | 检查网络/VPN，稍后重试 |
| 安全验证 | Facebook checkpoint | 在浏览器手动完成 FB 安全验证 |
| 限流 | 发送过于频繁 | 降低群发频率，增加群间隔 |
| API | 接口返回错误 | 可能是 FB 改版，需等待扩展更新 |

## 页面一直转圈（加载不出群聊）

这表示 **Telegram 网页本身还没进聊天**，扩展无法勾选或转发。请按顺序排查：

1. **群链接**：地址栏须为 `https://web.telegram.org/a/#-100xxxxxxxx`（从已打开的群复制），不要用 `#-000…` 这类占位 ID
2. **登录**：在同一标签页完成 Telegram 登录
3. **手动进群**：弹窗链接留空 → 打开 TG 首页 → 左侧点进目标群
4. **顶栏按钮**：若仍转圈，点蓝条 **「TG 卡住时点这里」** 回到首页再进群
5. **扩展**：在 `chrome://extensions` 对该扩展点 **重新加载**，再刷新 TG 标签页

只有左侧出现会话列表、中间出现消息，才算加载完成；此时再配置 FB 并勾选发言者。

## 如何发布新版本

本项目使用 GitHub Actions 自动构建和发布。每次发布新版本只需要创建一个 Git Tag 并推送即可。

### 发布步骤

#### 1. 确保代码已提交并推送

```bash
git status
git add .
git commit -m "你的改动说明"
git push origin main
```

#### 2. 创建版本 Tag

```bash
git tag -a v2.0.2 -m "Release version 2.0.2"
```

#### 3. 推送 Tag 触发自动构建

```bash
git push origin v2.0.2
```

推送后，GitHub Actions 会自动构建并创建 Release。
